A calm Android app for **tasks, habits and focus**. Offline, encrypted, no account, no ads.

- **Today first**: one screen with what's due, an "Up next" shortlist and one-tap focus sessions
- **Habit chains** with streaks, a history heatmap and vacation mode that doesn't break them
- **Private by design**: SQLCipher database with a Keystore-protected key, encrypted backups
- **Adaptive**: one layout across phone, foldable, tablet, desktop and Android XR
- **Production discipline**: Clean Architecture + MVI, Room schema checks in CI, screenshot tests, automated releases with release-please (v1.18 and counting)

`Kotlin` · `Jetpack Compose` · `Material 3` · `Hilt` · `Room` · `WorkManager` · `Navigation 3`

## 🧪 Experiment: [Mandre Launcher](https://github.com/sherrerapiqueras/launcher)

A **Pixel-like Android home screen** built on a clean AOSP Launcher3 (Android 17) baseline, where the home screen adapts to Android's system **Modes**: work, sleep, focus or your own.

- Native workspace, folders, dock and widgets, with Pixel-style presentation on top
- Modes-driven layouts on API 35+, with an app-owned fallback for API 31–34
- Designed before coded: accepted ADRs, a documented architecture and a 112-capability roadmap
- CI and branch protections in place from day one
